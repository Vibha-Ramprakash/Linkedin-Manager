Local installation

Install in five steps

Let the agent do the mechanical setup. Keep system changes and authentication under your control.

One-time login required
1

Clone the project and inspect the skills

The repository contains People Finder, Trend Scanner, Fit Checker, and Evidence Writer skill files, plus the dashboard and local bridge.

git clone https://github.com/Vibha-Ramprakash/Linkedin-Manager.git
2

Install the LinkedIn research route

Follow Agent Reach's current official guide. The tested setup installs only the LinkedIn channel.

agent-reach install --env=auto --system --channels=linkedin
3

Complete the human login

A visible browser opens. You complete sign-in and any security checkpoint yourself.

uvx mcp-server-linkedin@latest --login
4

Verify two harmless reads

The connection counts as working only when your profile and one people search return real, non-empty records.

mcporter call linkedin.get_my_profile sections="experience"
5

Start the local dashboard

Serve the workspace from localhost. Do not use a file URL for live research.

node live-server.mjs

Credibility boundaries

What the system will and will not do

The setup is designed for inspectable research, not hands-off LinkedIn activity.

Read only
Included

Research and drafting

People search, public profiles, company context, public posts, trend analysis, fit scoring, timing events, drafts, and content planning.

Excluded

Account actions

No connecting, following, messaging, inbox access, publishing, scheduling, profile changes, CAPTCHA bypass, or silent example-data fallback.

i
Use small, serial batches.This improves inspectability and personalization, but it does not guarantee account safety or platform permission. Stop if LinkedIn or your organisation blocks the activity.

When something fails

Troubleshooting without faking success

A failed or empty live run stays failed or empty. The dashboard never fills it with example profiles.

Read full operating guide
LinkedIn connection needs attention

Keep the visible browser open, complete any login or checkpoint yourself, then repeat the same harmless profile read. A configured connector is not proof of a live session.

The search returned zero people

Keep the live result empty. Try one recognizable role, one city, and plain market language later. Do not rapidly loop searches or substitute example records.

I requested ten people but received three

Ten is a maximum request, not a guarantee. The connector exposes no pagination or result-limit parameter. Keep the returned records, then use Add to run later if you need another small batch.

Trend Scanner has fewer contributors than People Finder

Only leads with supported role and company evidence can influence themes. Profiles without dated post evidence remain available for fit, drafting, and review but stay outside trend totals.

The visible browser closed or the run was interrupted

Completed evidence remains available. Restart the local bridge, verify the live read again, and do not assume unseen steps finished.
